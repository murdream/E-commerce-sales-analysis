# E-commerce-sales-analysis
## Описание проекта
Анализ транзакций интернет-магазина

**Что сделано:**
- подготовка и очистка данных в Python;
- расчёт ключевых метрик: общая выручка, количество заказов, средний чек;
- анализ выручки по категориям, регионам, месяцам;
- анализ распределения заказов по дням недели;
- написание SQL-запросов для проверки расчётов;
- построение дашборда в Power BI.

## Инструменты
- Jupyter Notebook (Pandas, NumPy, Matplotlib, Seaborn): подготовка данных, расчёт метрик, построение графиков
- SQL (DBeaver): выполнение запросов 
- Power BI: дашборд 

## Результаты

- Общая выручка: 5 109 775 ₽
- Всего заказов: 5 000
- Средний чек: 1 022 ₽
- Самый высокий месяц по выручке: май (479 772 ₽)
- Самая прибыльная категория: Electronics (1 829 899 ₽)
- Заказы по дням недели распределены равномерно
- Средняя оценка клиентов: 2.97 из 5
